# FKS-001: GET /products/{id} возвращает 200 для отсутствующего товара

## Окружение

- Сервис: FakeStore API
- Base URL: `https://fakestoreapi.com`
- Endpoint: `GET /products/{id}`
- Дата проверки: 21.09.2026
- HTTP-клиент: REST Assured 5.5.7

## Предусловия

1. FakeStore API доступен.
2. В каталоге отсутствует товар с ID `999999`.

## Шаги воспроизведения

1. Отправить запрос `GET https://fakestoreapi.com/products/999999`.
2. Проверить HTTP-статус ответа.
3. Проверить тело ответа.

## Ожидаемый результат

Сервер возвращает:

- HTTP-статус `404 Not Found`;
- JSON с информацией о том, что товар не найден.

## Фактический результат

Сервер возвращает:

- HTTP-статус `200 OK`;
- пустое тело ответа;
- заголовок `content-length: 0`.

## Severity и Priority

- Severity: Medium
- Priority: Low

Ошибка нарушает ожидаемый контракт REST API. Клиент может попытаться
десериализовать пустое тело как объект товара и завершиться с ошибкой.

Приоритет низкий, поскольку проблема обнаружена в демонстрационном API.
Для production-магазина приоритет необходимо пересмотреть.

## Дополнительная информация

- Воспроизводимость: 5 из 5 попыток.
- Автотест: `ProductApiTest.shouldReturnNotFoundForUnknownProduct`.
- Автотест временно помечен `@Disabled`.
- Поведение для отсутствующего товара явно не описано в публичной документации
  FakeStore API, поэтому ожидаемый контракт необходимо подтвердить у аналитика
  или владельца API.
