## 4. Рабочий процесс из чата

1. Подключиться к удалённому серверу в закрытой сети.
2. Принять участие в daily; пример задачи — автоматизация авторизации.
3. Посмотреть ТЗ в Confluence и существующие ручные тесты.
4. Создать отдельную branch и реализовать тесты в IntelliJ IDEA: подобрать
   элементы в браузере и описать шаги.
5. Сделать commit и push.
6. Пройти code review.
7. Добавить проект в Jenkins job и запустить build.
8. Если всё успешно, задача завершена.
