# Чек-лист материала из чата

Здесь перечислены только темы, которые указал Алекс. Чек-лист не расширяется
смежными темами без прямого запроса пользователя.

## Важно

- [x] **Selenide.**
- [x] **REST Assured.**
- [x] **Паттерны автоматизации.** Отдельно изучить Page Object.
- [x] **Flaky-тесты.** Способы борьбы, названные в чате:
  - рефакторинг;
  - более хорошие селекторы и локаторы;
  - совмещение UI- и API-тестов;
  - многопоточный запуск автотестов.
- [x] **Allure report.**
- [ ] **Jenkins (CI/CD).**
- [ ] **Selenoid.**
- [ ] **Темы ручного тестирования:**
  - функциональное и модульное тестирование;
  - функциональное и интеграционное тестирование;
  - функциональное и системное тестирование;
  - E2E.
- [ ] **Тестирование, связанное с изменениями:** `smoke → regression`.
- [ ] **Техника тест-дизайна:** эквивалентное разделение.
- [ ] **SQL.**
- [ ] **Mocks.**
- [ ] **Docker.**

## Дополнительно

- [ ] **Тесты Kafka.**
- [ ] **Нагрузочное тестирование.**

## Принципы автоматизации из чата

- [x] Тесты не имеют последовательности.
- [x] Тест 1 не вытекает в тест 2.
- [x] У каждого теста своя среда.
