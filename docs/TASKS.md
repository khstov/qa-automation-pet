# Задачи по обучению и pet-проекту

Список основан только на темах из чата с Алексом. Теорию изучаем параллельно с
практикой. Исходный код и конфигурацию меняет и запускает пользователь; Codex
объясняет материал, сохраняет конспекты и проверяет результат.

Отметка `[x]` означает, что реализация уже есть в проекте. Она не означает, что
тема уже изучена и её можно объяснить на собеседовании.
