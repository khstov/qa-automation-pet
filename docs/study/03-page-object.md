# 03. Паттерны автоматизации и Page Object

Статус: завершено 13 октября 2026 года.

Page Object — следующий обязательный блок из списка. Разбираем его только на
существующих UI-тестах проекта: `TextBoxPage`, `TextBoxTest`,
`RadioButtonPage` и `RadioButtonTest`.

## Что нужно понять

- что означает паттерн автоматизации;
- зачем нужен Page Object;
- что находится в Page Object;
- что остаётся в тесте;
- почему локаторы скрываются внутри объекта страницы.

## Первая практика

Сравнить `RadioButtonPage` и `RadioButtonTest` и своими словами объяснить:

1. где находятся локаторы;
2. где выполняются действия со страницей;
3. где описан проверяемый сценарий;
4. почему тест не должен самостоятельно искать элементы страницы.

Практика разобрана 13 октября 2026 года:

- локаторы находятся в `RadioButtonPage`;
- методы Page Object непосредственно работают с элементами страницы;
- `RadioButtonTest` задаёт порядок шагов и проверяемый сценарий;
- тест вызывает методы Page Object и не знает конкретные селекторы;
- изменение селектора требует правки Page Object, а не каждого теста.

Важно: автоматический запуск тестов при изменении проекта относится к CI/CD.
Паттерн автоматизации — повторяемый способ организовать тестовый код и
разделить ответственность при решении типовой задачи.

## Практика 2 — ответственность Page Object и теста

На примере `TextBoxPage` и `TextBoxTest` определить:

1. почему тестовые значения объявлены в тесте;
2. чем действие `setEmail` отличается от проверки
   `shouldRejectInvalidEmail`;
3. где нужно исправить код при изменении ID поля email;
4. зачем локаторы Page Object объявлены `private`.

Практика выполнена 13 октября 2026 года:

- тестовые данные принадлежат сценарию и передаются в методы Page Object
  параметрами;
- `setEmail()` выполняет действие, а `shouldRejectInvalidEmail()` проверяет
  видимое состояние страницы;
- изменение ID email-поля требует правки локатора только в `TextBoxPage`;
- `private` не позволяет тестам обращаться к локаторам напрямую и сохраняет
  инкапсуляцию.

Пользователь самостоятельно применил Page Object в сценарии Radio Button и
объяснил разделение ответственности. Блок завершён.
